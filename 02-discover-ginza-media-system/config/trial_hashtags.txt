# `./p2 interest trial-morning` が毎朝この一覧を読み、各タグについて
#   ./p2 interest fetch-note-hashtag <tag>

#
# 使い方:
#   - 1行1タグ。前後の空白は無視。
#   - `#` から行末まではコメント。空行は無視。

#   - タグ名は note のハッシュタグ表記そのまま（日本語可）。
#
# 注意:
#   - ここに書いても「取得」だけ。承認・記事生成は自動化されない（人間が管理画面で実施）。
