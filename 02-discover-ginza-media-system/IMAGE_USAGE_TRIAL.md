## 2. 利用可否ステータス定義

| ステータス | 定義 |
|---|---|
| **A. USABLE** | 公式情報・利用条件等から利用可能であることを**確認できる**（明示的な許諾・利用規約での許容・プレスキットとしての提供等、根拠が具体的に存在する） |
| **B. REVIEW** | 公式画像であることは確認できるが、転載・SNS利用条件が確認できない |
| **C. NOT_USABLE** | 転載禁止の明示、権利条件が第三者著作物であると判明している等、利用を避けるべき積極的な根拠がある |
| **D. UNKNOWN** | 画像の出所・性質自体を含め、判断材料が不足している |

**重要な運用原則**：「公式サイトに掲載されている」「OGP画像として取得できる」という
事実だけではUSABLEにしない——OGP画像の設定は本来ページのプレビュー表示（SNSやチャット
アプリでリンクを共有した際のサムネイル表示）を目的とした技術的な仕組みであり、
記事本文への埋め込みやSNS投稿画像としての二次利用を許諾する意思表示ではない。

## 4. note／X／LINEごとの画像要件（画像利用権を最優先）

| チャネル | 推奨要件 | 画像利用権上の注意 |
|---|---|---|
| **note** | 冒頭横長画像（記事のアイキャッチとして表示）、記事内各候補の紹介画像 | note記事は不特定多数に公開されるため、**埋め込みは実質的に「転載」に相当**——USABLEでない画像は埋め込まない |
| **X** | 横長・視認性重視、文字情報過多を避ける | 投稿画像はリポスト・保存・二次拡散されうるため、noteより**さらに慎重な判断が必要**——USABLEのみ使用可 |
| **LINE** | スマートフォン表示で内容が判別できる、正方形〜縦長でも可 | 公式アカウント配信は限定的な拡散だが、スクリーンショット等での再拡散リスクは残るため同様にUSABLEのみ |

**原則**：フォーマット適性（横長・視認性等）は画像利用権が確認できた後に検討する
二次的な条件であり、利用権が確認できない画像はフォーマットが適していても使用しない。

## 6. 代替方針の検討

公式画像がREVIEW段階に留まる間、note記事公開時点で使用できる選択肢：

| 選択肢 | 適用可否の検討 |
|---|---|
| **画像なし記事** | 最も安全。テキストのみで公開する場合の代替として常に選択可能 |
| **GINZA WHISKERS独自アイキャッチ** | ブランド共通のテンプレート（ロゴ・タイポグラフィ中心）であれば著作権上安全。イベント固有のビジュアルを含まない汎用デザインとして運用可能 |
| **AI生成の抽象的・編集的挿絵** | **要注意**：使用する場合は「季節感」「銀座の街並みの抽象的表現」等、イベント固有の作品・商品を模倣しない範囲に限定する。**パク・ヨンジェの絵画スタイルを模したイラストや、REGAL×SOMÈSのブーツの外観を再現した画像等は、たとえAI生成であってもイベント固有の著作物の模倣に該当しうるため避ける** |
| **現地で自ら撮影した写真** | 権利関係が最もクリアだが、本Trialのスコープ外（現地取材は今回実施していない） |
| **公式ページへのリンクのみ** | 画像を一切embedせず、「詳細はこちら」形式で公式ページへのテキストリンクのみ掲載——著作権上最も安全な代替案の一つ |

**今回のTrial記事（`NOTE_ARTICLE_TRIAL.md`）への推奨**：全候補の画像がREVIEWのため、
公開する場合は「画像なし」または「GINZA WHISKERS独自アイキャッチ＋各候補への公式
リンク」の組み合わせを推奨する。

## 7. Quality Gateとの接続仕様

`QUALITY_GATE_TRIAL.md`で定義したテキストの品質Gate（BLOCKER/WARNING/PASS）とは
別軸として、画像専用のGateを以下のとおり定義する。

| 画像ステータス | note埋め込み | X／LINE投稿 | 記事全体への影響 |
|---|---|---|---|
| **USABLE** | 可 | 可 | 影響なし |
| **REVIEW** | **不可**（埋め込まない。「画像なし」または独自アイキャッチで代替） | **不可**（SNS GateとしてはBlocker相当） | テキストGateには影響しない——記事自体はWARNING/PASSのまま公開可能（画像を使わない前提で） |
| **NOT_USABLE** | 不可 | 不可 | 同上。加えて、当該画像URLを候補リストから除外し、代替方針（§6）の検討を必須とする |
| **UNKNOWN** | 不可 | 不可 | 同上。追加調査（規約確認）を優先タスクとして記録する |

**設計上の判断**：画像の利用可否は、記事本文の品質（BLOCKER/WARNING/PASS）とは
独立した別Gateとして扱う——本文が完全にPASSでも画像がREVIEWなら「画像なし記事」
として公開する、という組み合わせを許容する（画像未確定を理由にテキスト公開まで
止める必要はない）。一方、**SNS投稿（X／LINE）は画像添付が前提となることが多いため、
画像USABLEが確認できるまでSNS Gateは通過しない**、という非対称な設計とした。

## 追記（2026-08-19）：Editorial Trust Layer確定による方針更新

本Trialの結論（全5画像REVIEW、次工程として「各サイトの利用規約ページの実際の確認」を
挙げていた）は、直後に確定した**Editorial Trust Layer**（`CLAUDE.md`第8章）により
運用方針が更新された。

- **「REVIEW→USABLE化のための利用規約調査」は通常運用の必須工程にしない**——
  Editorial Trust Layerの正式方針により、外部サイト画像は原則転載しない
  （明示的な利用許諾が確認できた場合のみ例外）。したがって本Trialが挙げた
  次工程「①各サイトの利用規約ページの実際の確認」は、**日常のnote記事生成では
  実施しない**——REVIEW判定の画像は速やかに「独自画像または画像なし」で
  代替する運用に切り替える。
- 個別に強い動機（例：将来的な提携・許諾交渉等）がある場合に限り、規約確認を
  例外的に行う余地は残すが、それは通常のTrial運用のスコープ外とする。
- 本Trialで整理した判定フレーム（USABLE/REVIEW/NOT_USABLE/UNKNOWNの定義、
  §1〜§5の情報整理手法）自体は今後も有効——**将来、独自撮影素材やGINZA
  WHISKERSが直接許諾を得た素材が増えた際の管理台帳フォーマット**として
  引き続き使用する。
