# Visual Asset Library（世界観挿絵・ジャンルアイコン仕様）

Project 02「AI GINZA EDITORIAL DESK」のビジュアル仕様書。2026-08-19、Human
Editor Reviewにより正式確定した。`CLAUDE.md`第8章「AI活用ポリシー」の
Editorial Trust Layer・Editorial Style Engineと矛盾しない、それらを前提とした
ビジュアル面の実装仕様として位置づける。`CONTENT_MODEL.md`・
`ARCHITECTURE_DRAFT.md`と同格の正式参照ドキュメントであり、Trial記録
（`NOTE_ARTICLE_TRIAL*.md`等）とは性格が異なる。

**確定日**：2026-08-19
**今回の作業範囲**：仕様統合・カテゴリマッピング・自動選択ロジック設計・
ファイル命名・配置ルールの確定まで。**画像生成そのものの自動実行・外部画像
取得・note投稿・X投稿・LINE送信・実コード実装はいずれも行っていない。**

## 1. ビジュアル全体方針（2階層構造）

Project 02のビジュアルは役割の異なる2階層に分ける。両者の役割を混同しない。

| 階層 | 役割 |
|---|---|
| **A. 世界観挿絵** | 「旬の銀座を届ける」入口ビジュアル。GINZA WHISKERSの編集メディアとしての世界観・銀座の象徴性・日本の四季を表現するアイキャッチ |
| **B. 個別ジャンルアイコン** | 各Editor's Choiceの内容をスマートフォン上で一瞬で判別できる視覚記号 |

## 2. 世界観挿絵

### 2.1 役割

- GINZA WHISKERSの編集メディアとしての世界観を示す
- 銀座の象徴性を伝える
- 日本の四季、日本らしさを表現する
- note冒頭やURLカードで目を止めてもらう
- 記事本文を読む前のアイキャッチとして機能する

**世界観挿絵では個別の催事・商品・展示作品等を直接描かない**。外部イベント
画像・商品画像・作品画像は使用しない（Editorial Trust Layerの画像方針と
整合、詳細は§7）。

### 2.2 WAKOモチーフの扱い（重要な制約）

WAKOの建物は、銀座を象徴する街並みモチーフとして**独自生成の挿絵に抽象化
して**使用する。**WAKO公式写真・公式画像・公式ロゴは使用しない**。公式
提携・監修と誤認されるような見せ方は避ける——時計塔のシルエット等、
抽象化された街並み要素としてのみ扱い、WAKOという固有店舗の宣伝・推奨と
受け取られる表現にしない。

### 2.3 6タイプ

世界観挿絵は年間1枚固定ではなく、季節・時期に応じて以下6タイプを切り替える。

| タイプ | モチーフ | 基調・雰囲気 |
|---|---|---|
| **SPRING** | 桜、春らしい小物、柔らかい光 | 明るい春の銀座 |
| **SUMMER** | 団扇、朝顔、風鈴 | 涼感、夏の夕方〜宵の銀座 |
| **AUTUMN** | 紅葉、秋の小物、読書・栗・銀杏等の文化・実りの気配 | 金、橙、深紅 |
| **CHRISTMAS** | 銀座のイルミネーション、クリスマスツリー、オーナメント、夜のWAKO（抽象化） | 「銀座のクリスマス」を表現。サンタ・トナカイを主役にしない |
| **NEW YEAR** | 門松、水引、独楽、梅または椿 | 正月・新春の空気。使用時期は年末〜正月初旬を想定 |
| **WINTER** | 正月後の冬。門松は使わない。椿、雪、冬木 | 澄んだ冬の空気。白、藍、金を基調 |

### 2.4 GINZA WHISKERSの署名表現

世界観挿絵の「GINZA WHISKERS」表記横には、**猫ではなく犬＝マロンの
シルエット**を使用する。ただし、瓦版記者マロンを世界観挿絵の**主役には
しない**——マロンの位置付けは「ブランド署名」「編集者の人格」
「Editor's Note」「記事末尾署名」に限定する。**世界観挿絵の主役は
「銀座」「四季」「日本らしさ」であり、マロンではない。**

### 2.5 Character Standardとの関係（2026-08-21追記）

マロン／コロンの造形・外見の一貫性を固定する仕様（Character Standard）
を`CHARACTER_STANDARD.md`として新設した。**本節が定める「マロンを
世界観挿絵の主役にしない」という原則（Character Dominance）は、
Character Standardの新設によって変更されない**——両者は独立した別概念
であり、詳細は`CHARACTER_STANDARD.md`§0を参照。

## 3. 個別ジャンルアイコン

### 3.1 役割・基本方針

各Editor's Choiceの内容をスマートフォン上で一瞬で判別できるための視覚記号。

- 一目でジャンルが分かる
- スマホで小さく表示しても判別できる
- 線が細すぎない
- 1アイコン1意味
- 細部を描き込みすぎない
- グローバルに理解しやすい
- GINZA WHISKERSらしい上品さを少し加える
- 円形バッジを基本形とする
- 色によるジャンル識別も活用する

### 3.2 グローバルスタンダード方針

訪日外国人利用を前提とする。ISO等の公共情報シンボル設計思想を参考にしつつ、
**完全な公共サインではなく、GINZA WHISKERS独自のEditorial Iconとして設計
する**。

- 日本語が読めなくても図柄で意味を推測しやすい
- 英語ラベルを併記可能
- **日本語版／英語版で図柄は共通、ラベルのみ差し替える**
- 文化依存が強すぎる表現を避ける

### 3.3 正式採用18ジャンルと基本モチーフ

| # | 日本語名 | ENラベル | 基本モチーフ |
|---|---|---|---|

ラベルは2行以内に収める。装飾的な細い書体は避ける。

## 4. Primary Category自動選択ロジック

今後の自動化では、候補ごとにPrimary Categoryを1つ持つ。Primary Categoryに
対応するIcon Libraryのアイコンを自動選択する。

**マッピング例**（既存のUX Type分類・contentType分類との対応イメージ、
確定的な自動変換テーブルではなく判断の目安）：

| 候補の性質 | Primary Category例 |
|---|---|
| レストラン企画 | FOOD |
| 展覧会 | ART |
| ライブ | MUSIC |
| 体験型ワークショップ | WORKSHOP または EXPERIENCE |

複数カテゴリ候補がある場合は、読者が最初に理解すべき体験ジャンルを
Primaryとする。**自動判定に迷う場合はHuman Editorへ確認する**——無理に
機械的な一意の答えを出さない（本プロジェクト全体の「推測しない」原則の
延長）。

**既存分類との関係（未確定・次回検討事項）**：本Icon Libraryの18カテゴリと、
既存の`uxType`（participate_workshop/exhibition_viewing/food_drink/
shopping_discovery/live_performance/other、`cms/src/lib/curation/
uxType.ts`）・`contentType`（event/news/exhibition/food/shopping/culture/
other、`classifyContentType.ts`）は、粒度も分類軸も異なり単純な1対1対応
ではない。自動マッピングテーブルの正式設計は、実コード実装に着手する際に
改めて行う（今回はスコープ外、§10「まだHuman Editor判断として残る項目」
参照）。

## 5. 季節挿絵の自動選択ロジック

世界観挿絵は日付に応じて自動候補を出せる設計とする。

| タイプ | 基本目安の時期 |
|---|---|
| SPRING | 3〜5月 |
| SUMMER | 6〜8月 |
| AUTUMN | 9〜11月 |
| CHRISTMAS | 11月末〜12月25日 |
| NEW YEAR | 12月26日頃〜1月上旬 |
| WINTER | 正月後〜2月 |

**固定日付だけで完全自動決定しない**——季節感・記事テーマ・Human Editor
判断を優先できるようにする（自動候補の提示までとし、最終選択はHuman
Editorが行う余地を残す設計）。

## 6. note／X／LINEでの配置ルール

### 6.1 note

| 配置箇所 | 使用素材 |
|---|---|
| A. 記事冒頭 | 世界観挿絵6タイプのうち1つ、季節・時期に応じて自動選択 |
| B. 各Editor's Choice | 18ジャンルアイコンから1つ、各候補のカテゴリに応じて自動選択 |
| C. Editor's Note | マロンの編集者人格を使用可能（署名例：「Maron, GINZA WHISKERS」または「瓦版記者マロン」）。ただし毎項目にマロンを出しすぎない |

### 6.2 X

- 世界観挿絵をURLカード／投稿画像として使用可能
- 個別アイコンは必要な場合のみ使用
- 情報過多にしない

### 6.3 LINE

- 個別アイコンでEditor's Choiceを視覚整理可能（3〜5候補程度）
- スマホ可読性を最優先

### 6.4 その他チャネルへの転用

Instagram等へ転用する場合も、同じIcon Libraryを使用可能とする。

## 7. 権利・安全ルール（Editorial Trust Layerとの接続）

本節は`CLAUDE.md`第8章のEditorial Trust Layer（画像・出典ポリシー、
2026-08-19確定）をそのまま維持・適用したものであり、新規の権利方針を
追加するものではない。

**禁止**：外部イベント画像の無断転載／OGP画像の無断転載／商品写真の無断
転載／展示作品の無断使用／外部ロゴの無断利用／公式画像のトレース／公式
提携と誤認される表現。

**使用可能**：GINZA WHISKERS独自撮影／GINZA WHISKERS独自生成画像／明示的に
利用許諾された画像／権利上問題のない素材。

WAKOは銀座の街並みモチーフとして独自生成の挿絵に使うが、公式ロゴ・公式
画像は使用しない（§2.2で既述、権利ルールとしても再確認）。

## 8. ファイル管理方針・命名規則

世界観挿絵6タイプ、18ジャンルアイコンは、Project 02のVisual Asset
Libraryとして管理する前提で設計する（実際のアセット生成・保存先は
実装時に確定、本仕様は命名規則の確定まで）。

### 8.1 世界観挿絵

```
world_spring
world_summer
world_autumn
world_christmas
world_newyear
world_winter
```

### 8.2 ジャンルアイコン

```
icon_food
icon_cafe
icon_shopping
icon_architecture
icon_art
icon_event
icon_night
icon_music
icon_beauty
icon_hotel
icon_wellness
icon_experience
icon_gift
icon_workshop
icon_photo
icon_family
icon_nightview
icon_rainyday
```

### 8.3 日英差分がある場合

日本語版・英語版を分ける場合は、末尾に`_ja`／`_en`を付ける
（例：`world_spring_ja`／`world_spring_en`）。図柄自体は共通のため、
ラベルテキストのみ差し替える運用であれば同一ファイルの多言語対応
（テキストレイヤー分離等）も選択肢になる——実装方式の確定は次工程。
